## One-time console setup

1. In Catalyst, open **Cloud Scale -> Authentication -> Set Up -> Embedded
   Authentication** and select **Web SDK v4**.
2. In **Social Logins -> Google**, copy the Development redirect URIs and ZAID.
3. In Google Cloud Console, create an OAuth 2.0 Client ID of type **Web
   application**. Add the exact JavaScript origins and redirect URIs copied from
   Catalyst.
4. Paste the Google Client ID and Client Secret into Catalyst and enable Google.
5. Create roles named `Administrator`, `Senior Officer`, `Investigation Officer`,
   `SCRB Analyst`, and `Read Only`. The Function maps these names to NETRA roles.
6. Add the judging/demo Google accounts to Catalyst users and assign roles.
   Keep public signup disabled for a police deployment after the roster is added.
7. Open **Authentication -> Whitelisting -> Authorized Domains**, add
   `netra-crime-intellig-zxhnvtwj.onslate.in`, and enable **CORS**. iFrame access
   is not required. Repeat this for the final Production domain.
8. In **Serverless -> Security Rules**, require authentication for the
   `ai_quickml` Advanced I/O Function after the first officer login is verified.
9. Repeat Google configuration with the Production ZAID and production app
   domain before enabling `REQUIRE_CATALYST_AUTH=true` in Production.

Do not put the Google Client Secret in `.env`, frontend code, or git. It belongs
only in Catalyst Authentication and Google Cloud Console.
