# Officer Gateway Reference Match

The backdrop was generated with the built-in imagegen tool from the user's reference, then converted to WebP without resizing. The original is `intelligence-backdrop-source.png`; the deployed image is `public/login/intelligence-backdrop.webp`.

Generation prompt: Create a background bitmap only, matching the reference's very light icy blue and white palette. Photographic Karnataka Vidhana Soudha at the extreme right, carved columns and dome, Indian flag, airy daylight. Keep the left 40 percent almost white for text. Center a delicate cyan geographic intelligence network with fine connections, a faint grid, and Karnataka silhouette. No UI, cards, text, logos, labels, dark areas, purple, or decorative blobs. All interface text and controls are rendered separately.

The initial panel combines the reference's email field and Continue button with Catalyst's native provider controls, without a sign-in selector. Continue mounts Catalyst's full native form, transfers the typed email and invokes its native next step. Password and recovery remain in Catalyst's form. Create an account carries the entered email into a name-and-email form and calls `auth.signUp`. Catalyst handles account verification and password setup; the app never collects or stores passwords.

The canvas overlay anchors animated junctions and moving signals to the background map and extends a sparse network across the full page. Nodes and their connected edges drift continuously without pointer input; pointer movement adds a local displacement. It pauses in hidden tabs and respects reduced-motion preferences. Feature cards and the gateway show an animated gradient border and elevation on hover; provider rows also have hover borders.

The four public counts are a build-time snapshot generated by `scripts/build-login-statistics.mjs` from the imported official-schema tables in `data/netra.db`. They are not an unauthenticated live query of Production records: 500 FIRs, 70 distinct accused profiles, 12 districts represented by FIRs, and 24 stations in the current dataset.
